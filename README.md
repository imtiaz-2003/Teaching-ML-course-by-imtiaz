### Lecture 16: Support Vector Machines (SVM)
**Theory**

**Practical**
- Implement SVM using Scikit-learn

### Lecture 17: Ensemble Techniques and Advanced Experiment Tracking
**Theory**
- Ensemble learning techniques:
  - Bagging (Random Forest)  
  - Boosting (AdaBoost, Gradient Boosting)  
- MLflow advanced usage:
  - Experiment tracking, model packaging, and deployment  
  - Integration with PyCaret and Valohai  

**Practical**
- Apply AdaBoost and Gradient Boosting

- Deploy an end-to-end pipeline using Valohai

### Lecture 18: Explainability in Machine Learning and MLOps Tools
**Theory**
- Importance of explainability in ML  
- Explainable AI tools:
  - SHAP (SHapley Additive exPlanations)

- Popular MLOps tools: MLflow and Valohai  

**Practical**
- Use SHAP for model interpretation and feature importance  
- Build and interpret models using PyCaret  
- Demonstrate a basic MLOps pipeline using MLflow or Valohai
