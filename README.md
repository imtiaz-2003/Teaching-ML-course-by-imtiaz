Week 4: Advanced Topics and Deployment
Lecture 16: Introduction to Support Vector Machines (SVM)
Theory:
Overview of Support Vector Machines
Understanding the kernel trick for non-linear decision boundaries
Applications of SVM in classification tasks
Practical:
Implement SVM using libraries like sci-kit-learn.
Apply SVM for real-world classification tasks (e.g., spam detection, image classification)
Lecture 17: Ensemble Techniques and Advanced Experiment Tracking
Theory:
Overview of ensemble learning:
Bagging (e.g., Random Forest)
Boosting (e.g., AdaBoost, Gradient Boosting)
MLflow Advanced:
Tracking experiments, packaging models, and deploying pipelines.
Integration with PyCaret and Valohai for seamless experimentation.
Practical:
Apply AdaBoost and Gradient Boosting for classification tasks.
Use MLflow with PyCaret to manage and track models effectively.
Deploy an end-to-end pipeline using Valohai for reproducible workflows.
Lecture 18: Explainability in Machine Learning and Introduction to MLOps Tools
Theory:
Explainability in ML:
Why explainability is crucial in real-world applications.
Key tools for explainable AI:
SHAP: SHapley Additive exPlanations
PyCaret: A low-code library offering built-in explainability tools
MLOps:
Introduction to MLOps principles: Collaboration, reproducibility, and scalability
Popular MLOps tools:
Valohai: End-to-end pipeline management for ML projects
MLflow: Experiment tracking and model lifecycle management
Practical:
Use SHAP to interpret model predictions (e.g., feature importance visualizations).
Experiment with PyCaret to quickly build, compare, and interpret models.
Demonstrate a basic MLOps pipeline with Valohai or MLflow.
Lecture 19: Saving, Loading, and Deploying Models with FastAPI

Introduction to FastAPI: setup and key features for building APIs
Practical: Create a simple API using FastAPI to serve a trained ML model locally
